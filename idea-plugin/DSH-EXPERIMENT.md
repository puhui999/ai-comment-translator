# DSH Agent 正式实验版

分支：`codex/dsh-agent-sidebar`。版本：`0.2.0-rc.1`。面向 IDEA `2026.2.0.1 / 262.8665.337`，沿用固定 DSH `0.1.5-rc.2` 的完整 Web 工作台。这是本地正式实验候选包，尚未发布到 Marketplace 或 GitHub Release。

## 本轮变化

- 增强模式由短角色说明和关联 Skill 组成；通过 DSH 原生技能机制读取内容，不替换原有工具、权限和项目规则。
- 助教自动加载内置 `ide-code-tutor`，包含查证源码、分步解释、示例和理解检查的工作流程。
- 自定义模式可以填写角色说明、选择最多 8 个当前可用 Skill，也可以仅选择 Skill。没有配置时不能保存；失效绑定会明确提示。
- 使用现有 DSH 模式菜单及原生弹窗，主题继续跟随 IDEA。通用模式不强制加载额外 Skill。
- 启动后可以直接在当前 IDEA 项目开始对话。添加其他工作区使用 DSH 官方页面内目录选择器，可直接在侧栏完成。
- 会话和 DSH 模型设置使用 IDE 配置目录持久保存，运行时安装包仍放缓存。旧预览数据只在首次迁移时复制，保留原数据并避免覆盖现有正式数据。
- 选区的目标会话、模式和 Skill 绑定在发送时固定；后续切换不改变已经提交的选区。Skill 变更从后续轮次生效。

## 安装和配置真实模型

1. 从本分支构建 `idea-comment-translator-0.2.0-rc.1.zip`，在 IDEA 的 **Settings → Plugins → Install Plugin from Disk** 安装。
2. 打开受信任的本地项目，打开右侧 **DSH Agent**。需要 Node.js 24；若自动查找失败，在启动页 **设置** 中指定 Node 路径。
3. 首次自动安装固定 DSH 运行时。已有安装也可通过 **Settings → Tools → DSH Agent** 指定，版本必须匹配。
4. 在 **DSH 原生设置** 中配置模型服务、地址、模型和 API Key。DSH 的配置与翻译功能独立；插件不会复制翻译凭据或写入测试模型地址。
5. 选中代码，执行 **发送选区到 AI 助教**；或者直接在 DSH 输入框提问。通过输入栏的模式菜单配置自定义模式与 Skill。

内置助教 Skill 随插件提供。其他 Skill 来自当前 DSH 的原生发现与插件机制；先在 DSH 中准备好，再在自定义模式里选择。已有会话按其实际工作区及原生配置列出可用技能；未打开会话时配置的是新会话默认模式。

切换模式不会删除历史。此前加载过的技能材料可能仍在会话记录中，本轮声明的模式绑定决定当前增强行为；用户主动调用的原生 Skill 保持可用。

重启沿用 DSH 的取消语义：尚未开始的原生排队消息会被取消，需要重新发送。插件不会自动恢复被取消的任务；重试旧请求也不会把取消误报为成功。已保存的历史、模式配置和 Skill 快照不等同于自动恢复任务执行。

## 首轮真实实验

建议在一个小型项目中依次完成：

1. 助教解释选中的函数，继续追问一个相关定义，检查回答是否引用了实际源码。
2. 要求 Agent 写一个最小示例并运行测试，观察原生工具及权限交互。
3. 新建自定义模式，仅绑定一个自己的 Skill；发送相同选区，比较工作流程是否改变。
4. 在两个会话之间切换不同模式，并在运行中提交下一段代码，检查后续轮次的绑定是否正确。
5. 通过 **IDE 助手 → 重启 Agent** 重启，再从原生历史中打开会话，检查模式、模型设置及历史是否保留。

遇到失败时保留报错、所用模型、具体步骤和预期行为即可，不需要提供 API Key。模型的教学质量及第三方 Skill/MCP 的行为需要在实际配置下验证。

## 开发验证

```sh
cd idea-plugin
./gradlew test buildPlugin
```

以下命令从仓库根目录运行。集成检查使用发布的完整 DSH 运行时和本地流式模型夹具：

```sh
DSH_TEST_RUNTIME=/tmp/dsh-agent-dev-runtime node scripts/dsh-agent-integration.mjs
node scripts/dsh-bridge-reservation-test.mjs
```

本轮 225 项 JVM 测试通过。完整运行时集成检查保留 27 个原生工具，14 次夹具模型请求覆盖模式、Skill 注入与冻结、模板持久保存、原生排队取消及工作区初始化；另外 3 项故障注入检查覆盖新会话预留和重试隔离。真实模型的教学效果仍待用户在 DSH 中配置后验证。

本机 IDEA 图形界面已验证首次自动安装、原生目录选择、仅绑定 Skill 的保存、重启后的模板回显、原生空白会话继承与模型设置入口。验收使用独立实验配置目录，未写入测试模型地址或凭据。

夹具只用于自动化检查，不进入正式默认配置。预览阶段的历史验证记录见 [DSH-PREVIEW.md](DSH-PREVIEW.md)，桥接协议见 [资源说明](src/main/resources/dsh/README.md)。
