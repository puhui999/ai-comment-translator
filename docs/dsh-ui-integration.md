# DSH 原生侧栏界面

## 设计约束

读取为：IDE 中的 Agent 对话侧栏，面向阅读源码和学习编程的开发者，采用 DSH 原生组件与宿主 IDE 的配色，保持紧凑、克制。

本次是在已选定的 DSH 界面上打磨：视觉冒险度 2/10，保留熟悉的工作台；动效强度 2/10，只使用原生交互反馈；信息密度 7/10，把空间留给源码与对话。

用户反馈：“页面布局，UI 按钮相关的直接在 DSH 上扩展。现在这样一半黑一半白，太难看了。”由此确定以下约束：

- 页面、输入框、菜单与弹窗统一跟随 IDEA 明暗主题。
- 正常对话时只显示完整 DSH 页面，移除外围 Swing 模式工具栏和常驻连接状态。
- 使用 DSH 原生插槽与组件增加操作，保留原有会话、模型、工具、轨迹及文件入口。
- 模式是高频单选操作，放在输入栏附近；运行设置和重启是低频命令，收进菜单。
- 自定义提示词使用原生弹窗，支持取消、校验和键盘操作。
- 选区保留真实换行和缩进，文件位置和未保存信息简洁显示。

## 功能契约

用户应能立即找到输入框和当前模式，切换通用、助教、自定义模式，发送源码选区并继续完整 Agent 对话。加载与失败时提供具体恢复操作；已连接、已加载等日常状态不长期占据对话面积。

DSH 尚未启动或页面无法加载时，IDE 提供跟随主题的启动与恢复界面。DSH 成功加载后，由 DSH 内部界面承担操作。不同会话分别保存模式，排队选区保留提交时的模式，原有工具与权限设置继续生效。

## 技术边界

Client 扩展通过 DSH 的 slot registry 与 theme runtime 工作。Host 提供同源 Cookie 鉴权的模式和命令入口，IDE 的私有 Bearer token 不进入浏览器。启动配置通过有限的 `settings`、`restart`、`retry` 命令交回 IDE；不提供任意脚本或 URL 执行入口。

主题仅传输明暗标记与受限的颜色值，不接受 CSS 文本。主题切换与对话状态同步彼此独立，不重建会话或重复发送源码。

`preview.2` 阶段保留提示词模式。后续 `0.2.0-rc.1` 在同一套 DSH 原生菜单和弹窗中加入模式关联 Skill，详见 [正式实验说明](../idea-plugin/DSH-EXPERIMENT.md)。

## 验收重点

- 深色与浅色宿主下，工作台、菜单、弹窗和加载状态明暗一致。
- 窄侧栏中模式入口可见，菜单不被遮挡，自定义提示词可编辑、取消和保存。
- 模式切换精确作用于当前会话，选区发送与重试不回退。
- 运行设置能从 DSH 打开，重启后主题和会话状态恢复。
- 鉴权、受限命令、颜色校验及原有完整 DSH 工具链集成通过。
